# 🌤️ Weather App

A simple and responsive weather application that fetches real-time weather data using a Weather API. Users can search for any city and instantly view the current weather conditions.

## Features

- Search weather by city name
- Displays current temperature
- Shows weather condition
- Displays humidity
- Shows wind speed
- Dynamic weather updates using API
- Responsive design

## Built With

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- WeatherAPI

## API

This project uses **WeatherAPI** to fetch real-time weather data.

You'll need your own API key if you want to run the project.
